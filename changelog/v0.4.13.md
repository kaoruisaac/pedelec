# v0.4.13

## Added
- Report rejected App Tool calls with invalid arguments or unknown tool names through the existing Session error event, so applications can observe the failure without automatically ending the active turn. Error events omit raw arguments and detailed schema validation messages.
- Support `additionalProperties` in SDK Tool Args object schemas, including nested objects, to let developers explicitly allow or reject extra fields.

## Changed
- Validate App Tool arguments exactly as provided. Agent-supplied `timeoutMs` is now treated only as ordinary tool data when allowed by the schema; execution timeouts are determined by the Tool definition instead of being overridden through arguments.
